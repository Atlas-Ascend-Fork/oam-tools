# 容易误读的现场字段

没有单位/量纲定义的传感器值或告警负载只按原值引用，不能由字段名猜测比例因子换算成电流、温度等物理量。

- `para base` 是任务参数块地址，不是全部 GM buffer 的合法地址区间。非空、看起来对齐的 `args` 和分配/释放计数配平，都不能证明访问合法；须关联实际分配区间、对象大小及访问偏移/长度。没有这些数据时保留 GM 指针/越界分支，不编造区间。
- 打印值未超 48 位只说明该值的数值位宽，不证明映射、对象范围或实际访存合法。`args ... after execute` 是执行后快照，不直接提供故障指令的有效地址，也不证明执行前参数、间接指针或其生产者正确；因此不能从它推出错误地址必由 kernel 内部计算产生。
- `argsSize=24` 只给参数块字节数，`tilingKey=0` 只给该字段值；二者不能确定三个值的语义、是否指向 tiling 或内部标量值的来源。`task_id=0`、创建一条流、只打印一个失败任务，也不证明本次只有一个任务或没有更早的生产者/写入者；须有覆盖该执行阶段的任务记录。
- 字段按完整名称逐项核对：`error code`、单元的`errorCode`、`mte error info`和`fixp_error0 info`不是同一个字段，某项为零不能改写为其他项为零；非零的info原始值也不自动等于该单元已报错。引用hash、PC或地址时保留完整字符串，不把多个地址压缩成可能改变数值的省略写法。正文和摘要均与同一来源行或提取视图核对。
- 对象创建、ATRACE初始化、流创建和程序注册不证明任务已经launch；只有明确下发/执行事件才能作为对应起点。耗时先核对两个事件的语义、对象和时钟，不能用创建对象到异常的间隔冒充kernel运行时间。PC与入口的差值是代码地址偏移，不表示第几条动态指令、首次执行、运行时长或故障可重复性；需要指令映射、执行记录或多次实验支持。
- `model_id/stream_id/task_id`是对象标识，不是当前存活数量。图或执行资源数量来自匹配作用域的创建/销毁、驻留统计或完整枚举；编号可能跳号、复用或继续递增。框架捕获图、Runtime模型实例和驱动资源也不必一一对应，不能由最大ID换算图数或资源用量。
- `errorStr` 的非法访问解码证明保护检查触发，不等于物理 RAS/ECC 告警。未提供 ECC/RAS 只说明缺少这类证据，其他硬件检测或受控对照仍可支持硬件候选；`error code=0`、初始化成功或正常退出均不能单独排除硬件故障。某单元错误位为零也不能排除上游参数、生产者或同步问题。
- FIXP 是固定功能处理流水线，不应称为标量执行单元。L0C 是 Cube 累加结果缓冲；访问越界可以由地址、步长、传输范围或状态问题引起。只由现有地址/长度等约束缩界，不能仅凭报错文本断言唯一参数、具体数值或通道模式。同步建议须核对芯片及 API 的实际生产者/消费者流水线，不套用 `PIPE_S` 等猜测组合。
- `scalar`指标量控制/访存路径，FIXP是另一条固定功能流水线。msaicerr的`ccu_mpu_err`及`SU_CCU_MPU_ERR_T0`将scalar internal-buffer越界列在CCU/SU错误中；另有单独的scalar UB越界和除零定义。这些错误不能互相替代，同时打印`fixp_error`、`mte error info`等字段也不证明这些单元均发生故障。没有适用型号的位定义时引用原始值和`errorStr`，不自行解码异常位或具体化缓冲区。定义来源为oam-tools的`src/msaicerr/ms_interface/constant.py`，使用时仍核对现场型号及版本。
- 屏幕日志与 plog 中同一次寄存器转储是重复观测，不算多个独立来源；按同一任务标识引用即可。正常释放统计只描述回收结果，不能排除早先的 OOM、越界或生命周期错误。
- 构建目录、kernel 名称和“错误版”文件名只提供假设线索，不证明故障注入设计、某变量的取值、已成功复现或已完成修复验证。源码、参数转储或实验记录未提供时，明确具体实现仍待核实。
- C++ 符号需要解释参数类型时，用 `c++filt -n '<原始符号>'` 校核；`-n` 保留 Linux 风格符号的前导下划线，避免 macOS 默认剥离。检查 stdout 是否实际转换，返回码为 0 仍可能原样输出；缓存告警也不必然表示解码失败。无法可靠解码时保留原符号。类型信息不能证明指针值、对象大小或访问合法性。
- 名称提示的上游原因可作为优先检查方向，但修复必须带成立条件。例如名称提示除零而原文只证明非法访问时，应分别给出访问边界检查与“若源码证实除零则保护除数”的方案；不能将除数为零、具体指令或其后地址计算当作日志事实。
- 题面环境与实际加载日志的版本不同时，两者分别列出并说明冲突，不擅自选择一个版本作为已确认的复测条件。推荐精确工具命令、选项或编译开关前，核对现有版本的帮助/文档；无法核对时给工具目的和所需输入，不补造参数。
