# Environment Setup

You have installed the toolkit software package in the CANN operating environment. For details, see  [CANN Software Installation](https://www.hiascend.com/document/detail/en/CANNCommunityEdition/910/softwareinst/instg/instg_0000.html).

After the CANN software is installed, log in to the environment as the CANN operating user and run the  **source $_\{INSTALL\_DIR\}_/set\_env.sh**  command to set environment variables.  Replace  _$\{INSTALL\_DIR\}_  with the CANN component directory. For example, if the installation is performed by the  **root**  user, the default file storage path is  **/usr/local/Ascend/cann**.

After setting the environment variable, you can directly run the  **asys**  command to use the asys tool without navigating to the directory where the asys tool is located.
