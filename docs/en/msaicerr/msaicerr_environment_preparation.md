# Preparing the msaicerr Tool Environment

<!-- md-trans-meta sourceCommit=2a887466d2e2283344c9f9e8c9427fce31c3c901 translatedAt=2026-10-10T12:13:58.480Z pushedAt=2026-10-15T10:49:24.493Z -->

The Toolkit software package has been installed in the CANN running environment. For details about the installation, see the *CANN Software Installation*.

After installing the CANN software, when you compile and run programs as the CANN running user, log in to the environment as the CANN running user and run the **source \$_\{INSTALL\_DIR\}_/set\_env.sh** command to set environment variables. Replace **\$\{INSTALL\_DIR\}** with the storage path of the installed CANN software. For example, if the software is installed by the root user, the default storage path is **/usr/local/Ascend/cann**.

Before using the msaicerr tool, go to the directory where the **msaicerr.py** script is located in **$\{install\_path\}/tools/msaicerr**.
