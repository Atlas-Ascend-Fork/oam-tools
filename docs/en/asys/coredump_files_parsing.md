# coredump File Parsing

## Description

Parses coredump files.

## Precautions

The coredump parsing feature depends on gdb, which must be installed in advance. You can install gdb using a package management tool (for example, apt-get install gdb or yum install gdb). For detailed installation steps and usage, see the [GDB official documentation](https://sourceware.org/gdb/).

## Command Format

```bash
asys analyze -r=coredump --exe_file=filename --core_file=filename --reg=reglevel --symbol=value --output=path
```

## Description

- **r**: Mandatory parameter, indicating the parsing mode, which is set to **coredump** here. When a process is interrupted and exits during task execution, the software reports errors such as Segmentation fault upon exit. You can use this function to parse the core file generated by the coredump and obtain a stack file in stackcore format (\*.txt file) for subsequent locating.
- **exe\_file**: Executable file when the program core dumps, which is set to a file name with a path here. This parameter is mandatory in coredump mode and must match core\_file; otherwise, the parsing result is incorrect.
- **core\_file**: Core file generated when the program core dumps, which is set to a file name with a path here. This parameter is mandatory in coredump mode and must match exe\_file; otherwise, the parsing result is incorrect.
- **reg**: Mode for adding register data in the coredump function. Only 0, 1, and 2 are supported, and the default value is 0. This parameter is optional in coredump mode.
    - 0: Do not add register data.
    - 1: Add one piece of register data for each thread.
    - 2: Add register data to all stacks of a thread (consumes more Host resources and is time-consuming).

- **symbol**: Parsing mode of the coredump function. Only 0 and 1 are supported, and the default value is 0. This parameter is optional in coredump mode. A nonexistent address or stack overflow may cause the asys tool to fail to parse.
    - 0: Parse all lines with addresses into a file in stackcore format, and display Ignore for other lines, indicating that they are skipped and not parsed.
    - 1: Parse only the in ?? \(\) lines, and keep the original gdb stack data for other lines.

- **output**: Optional parameter. Its value is used as the path prefix of the result output directory of the asys tool, that is, the final output directory is **\{output\}/asys\_output\_timestamp**. If the output parameter is not specified in the command line, the output results are stored in the directory where the command is executed. If the value specified for output is empty, is an invalid string, or the specified path directory has no write permission, or directory creation fails, the asys tool exits and reports an error.
